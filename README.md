# 數列卡皮巴拉

國小一、二年級的數列（數數模式）練習遊戲，在網頁上操作，支援平板觸控和電腦鍵盤。

## 指令

```bash
npm install      # 安裝套件
npm run dev      # 開發伺服器 http://localhost:5173
npm test         # 題目產生器的單元測試
npm run build    # 型別檢查＋打包到 apps/web/dist
```

## 專案結構

```
packages/game-core/   題目產生器、關卡設定、答案檢查、錯誤說明（不依賴 UI，之後後端也能共用）
  src/levels.ts       關卡設定：每關的數數規則、數字範圍、題型
  src/generator.ts    出題、產生錯誤選項
  src/answer.ts       答案檢查、答案唯一性檢查
  src/explain.ts      規律說明（「每次多 5」「15 再多 5 是 20」）
  src/hints.ts        三層提示
  src/scoring.ts      計分、星星、關卡與難度解鎖
  test/               單元測試：每個關卡抽 1000 題檢查
apps/web/             Vue 3 + Vite 前端
  src/store.ts        進度與設定（存在瀏覽器的 localStorage）
  src/speech.ts       題目朗讀（瀏覽器內建語音，優先選台灣華語）
  src/sound.ts        音效（Web Audio 即時合成，不需要音檔）
  src/components/     地圖、作答畫面、石頭數列、數字鍵盤等
```

課綱原文與教材參考放在上一層的 [`../docs/`](../docs/)，審查用的 `/review-math` 等工具設定在上一層的 `.claude/`，之後做其他遊戲也能共用。

## 遊戲規則

- **三種難度**（地圖上切換，兩種難度的星星、解鎖分開記錄）：

  | 難度 | 內容 | 開放條件 |
  |---|---|---|
  | 簡單 | 5 個數、1 個空格；選擇題和補空格 | 依地圖順序解鎖 |
  | 困難 | 7～8 個數、2～3 個空格，可以連續兩格、可以在開頭；只出補空格 | 這關簡單版拿到 2 顆星 |
  | 天才 | 一律 3 個空格，再混合「不從倍數開始」「跨過整十、整百」「往回數（二年級）」 | 這關困難版拿到 2 顆星 |

  多個空格時，點空格選要填哪一格；「確定」鍵會先跳到下一個空格，全部填好才一起檢查，答錯時填對的格子會保留。
  困難、天才版的「10 個一數」放寬到 100 以內（50 以內排不下 7～8 個數），乘法關卡會往回數；乘法不用「不從倍數開始」，否則就不是那一段乘法了。
- **地圖**：每學期一條石頭小路，終點是溫泉。每學期的第一關一定開著，老師可以直接跳到正在教的學期；其他關卡要前一關拿到至少 1 顆星才解鎖。
- **再試一次**：第一次答錯會打開第 1 層提示、劃掉選錯的選項，讓孩子再試一次；第二次還錯才公布答案和說明。
- **三層提示**：① 在相鄰兩個數之間標出「+5」② 說出規律「每次多 5」③ 引導「15 再多 5 是多少？」，都不直接說出答案。
- **星星**：自己第一次就答對 2 分，用了提示或第二次才答對 1 分，答錯 0 分。滿分的 90% 以上 3 顆星（5 題裡最多 1 題需要幫忙）、60% 以上 2 顆、30% 以上 1 顆。每關記錄最好的成績。
- **朗讀**：每題出現時自動唸出數列和題目，選擇題會唸出選項；提示、對錯說明也會唸。可以在地圖頁關掉自動朗讀，作答時按 🔊 可以再唸一次。
- 進度只存在這台裝置的瀏覽器裡；清除網站資料或換裝置會從頭開始。

## 新增關卡

在 `packages/game-core/src/levels.ts` 的 `LEVELS` 加一筆。規則用 `StepRule` 描述：

| 欄位 | 意思 |
|---|---|
| `step` | 每次加多少，負數是往回數 |
| `min`、`max` | 數列中每個數的範圍 |
| `startMultiple` | 第一個數必須是 `step` 的倍數（例如九九乘法） |
| `crossEvery` | 數列必須跨過這個數的倍數（例如 `100` 代表跨過整百） |

加完跑 `npm test`：測試會自動檢查新關卡出得了題、數字不超過課綱範圍（一年級 100、二年級 1000）、答案唯一。

## 出題原則

- 空格以外至少有 3 個數，答案才唯一（`2、4、□` 可能是 6 也可能是 8，不能出）。
- 依課綱 R-3-2 備註，說明規律時用「每次多 3」這類文字，不出現公式。
- 選擇題的錯誤選項模仿常見錯誤：以為是 1 個一數、多跳一次、差 1、十位算錯；不會出現題目上看得到的數。
- 說明從看得到的數往空格推：「15 再多 5 是 20」「比 50 少 10 是 40」；乘法關卡另外補上「4 的 5 倍是 20」（N-2-6）。
- 一回合由易到難：選擇題在前，補空格依空格位置（最後 → 中間 → 第一個）排在後。
- 關卡範圍配合教材進度：一下的 2、5、10 個一數在 50 以內，一上的倒著數在 10 以內，乘法依段次分關。
